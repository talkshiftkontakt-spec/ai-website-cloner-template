# Competitor Synthesis + Taste Skill Redesign

**Design Read:** Redesign-preserve for a Kraków medical-psychology clinic homepage, trust-first language for families and adults, leaning toward preserved Pomorska brand tokens (Playfair + sage green) with competitor-informed layout patterns.

**Dials:** DESIGN_VARIANCE 6 | MOTION_INTENSITY 5 | VISUAL_DENSITY 3

## Competitor patterns adopted

| Pattern | Source | Applied to Pomorska |
|---------|--------|-------------------|
| Persistent "Umów wizytę" CTA in header | Przylądek Równowagi, PsychoMedic | Header CTA → `#formularz-kontaktowy` |
| Large asymmetric hero + immediate value prop | Przylądek Równowagi | Split hero, left copy / right photo |
| Transparent pricing cards | PsychoMedic, Gabinety Rozwoju | 2-column pricing cards instead of hairline list |
| Specialist grid with roles | All competitors | Preserved 14-member grid, elevated hover |
| Trust / registration info near top | PsychoMedic | Trust strip under hero (godziny, lokalizacja) |
| Calm whitespace, low density | Medical norm | py-24 sections, max-w-7xl |

## Preserved (non-negotiable)

- Nav labels: strona główna, Specjaliści, Oferta, cennik, Kontakt
- Section titles: Gabinety Pomorska w Krakowie, Czym się zajmujemy?, Nasz zespół, Umów wizytę
- Brand colors: `#134340`, `#879d91`
- All Polish copy verbatim from original site
- Footer structure: Informacje, Kontakt, Lokalizacja

## Rejected competitor patterns

- Purple accent (Gabinety Rozwoju) - off-brand
- Cookie-heavy clutter
- Dense mega-menus (PsychoMedic 964 nav links)
- Generic Inter-only typography
