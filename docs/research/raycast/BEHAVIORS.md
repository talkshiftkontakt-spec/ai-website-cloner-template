# Raycast Homepage — Behaviors

## Scroll
- Native scroll (no Lenis)
- Navbar stays fixed; appearance largely unchanged on scroll (transparent floating bar throughout)
- Some sections fade-in-up on enter (class `page_fadeInUp`)

## Hero
- Canvas animation: red diagonal geometric beams with glow behind headline (time-driven)
- Fade-in-up on hero text

## Features dock
- INTERACTION MODEL: click-driven (dock items)
- Clicking dock icons switches the Raycast window mock content
- Active item gets highlight + label tooltip ("Clipboard History")
- Caption below updates per feature

## Extension highlight
- INTERACTION MODEL: click-driven tabs (Productivity, Engineering, Design, Writing)
- Horizontal carousel of extension cards; arrow buttons navigate
- Active tab has backdrop pill

## Testimonials
- Embla carousel, horizontal scroll of avatar cards
- Likely drag/autoplay

## Community YouTube
- Horizontal ticker/carousel of video thumbnails

## Hover
- Nav links: color → white
- Buttons: slight opacity/brightness
- Cards: subtle border/brightness lift
- Footer links: color → white

## Responsive
- Desktop 1440: full nav links, multi-column grids
- Tablet 768: nav may compress; grids → 2 col
- Mobile 390: hamburger or simplified nav; stacks to 1 col; hero title smaller
